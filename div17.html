Programar é como escrever uma receita de culinária para uma máquina. O computador executa cada comando na ordem exata que você determina. Ela serve para criar sites, aplicativos de celular, jogos e sistemas inteligentes.

Passo a passo para aprender programação

1° Lógica de programação

  • A lógica é obrigatória
  • Pense em uma receita de bolo, uma ordem exata de ações que precisa ser seguida
  • É a arte de ensinar o computador a resolver problemas.

2° Escolha uma linguagem

  • Escolha apenas uma para não ter confusão no aprendizado
  • JavaScript e HTML/CSS são ótimos para criar sites
  • Você pode saber mais no site da W3schools

3° Pratique todo dia

  • O aprendizado deve ser ativo
  • Não assista apenas aulas. Digite e teste o que aprendeu
  • Crie projetos simples

Tudo sobre tesouro direto

Você sabe o que é tesouro direto?

O Tesouro Direto é um programa do Governo Federal brasileiro, criado em 2002 em parceria com a B3 (a bolsa de valores do brasil), que permite a pessoas físicas comprarem e venderem títulos públicos de renda fixa pela internet.

Vantagens

  • Segurança: Os títulos são garantidos pelo governo federal, o que representa o menos risco de crédito do mercado.
  • Acessibilidade: É possível começar a investir com valores muitos baixos.
  • Liquidez diária: O investidor pode vender os títulos de volta para o governo a qualquer momento.
  • Diversidade: Existem opções pós-fixadas como a (Selic), atreladas á inflação (IPCA+) e prefixadas para diferentes metas.

Desvantagens

  • Tributação: Há cobrança de imposto de renda com tabela regressiva e do imposto sobre operações financeiras (IOF) para resgates em menos de 30 dias.
  • Marcação a mercado: Vender o título antes do vencimento pode gerar perdas ou ganhos inesperados devido a oscilação nos preços dos papéis.
  • Taxas: Embora tenha caído para zero em muitos títulos novos do tesouro selic até um limite, alguns investimentos ainda podem ter taxas de custódia da B3.
